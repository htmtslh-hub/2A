# Sản phẩm thương mại

Mỗi loại sản phẩm nằm trong một thư mục riêng:

- `giao-dien-web/`: mã nguồn, ZIP, quy chuẩn, hướng dẫn, công cụ và hồ sơ của giao diện web đang bán.
- `skill-prompt/`: skill và prompt.
- `agent/`: agent.
- `newsproduct 1/`, `newsproduct 2/`: tên nhóm tạm thời, đổi khi có sản phẩm tương ứng.

Ảnh và bản demo công khai của giao diện web vẫn nằm ở `../public/previews/` và
`../public/demos/` để URL trên cửa hàng không thay đổi.
