# AeroSix 1.0.0

A dark precision bicycle showroom inspired by the supplied System Six reference. Read CUSTOMISE.md first: ten steps, twelve complete AI prompts and a counted edit map. Extract all nine files and open index.html beside assets/. No framework, build, external font, CDN, account or API.

## Included and working
Six core files plus three original generated WebP bicycle photographs: bike-black.webp, bike-green.webp and bike-chalk.webp. They depict one concept bicycle in three visual finishes. Previous/next, keyboard arrows and horizontal pointer swipes change finish with a finite directional transition. Six example frame-size choices update the local summary. Four component hotspots open detail dialogs. Search filters the one model; no-result state works. Menu closes on links, Escape and resize; dialogs restore focus. Add unique finish/size configurations to a session-only enquiry bag, remove them, or prepare an email in a mail application. No email is automatically sent. See it in action plays a 4.2-second local design sequence, explicitly not riding footage. Replay and close work. Native specification accordions work without JavaScript. Engineering has a scroll-linked bicycle image/rule plus finite reveals.

Motion defaults ON on every opening, including OS reduced motion and old saved-off values, per product policy. Pause motion applies to this visit only; reload enables motion. Finite requestAnimationFrame timelines work without CSS animations or Web Animations, cancel prior transitions and have no idle RAF loop. The action sequence stops when closed or the document is hidden. NoJS retains the full hero, static finish images, specifications, navigation and email. Missing artwork leaves text/actions available. Relative paths support file:// and static hosting. System fonts only, no network font dependency.
