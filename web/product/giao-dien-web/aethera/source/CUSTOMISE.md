# Customise Aethera®

1. Extract the complete ZIP archive. Keep the original ZIP untouched and create a working copy before making changes. Read `README.md` and `LICENCE.txt`.
2. Install Node.js 20.19+ or 22.12+. Inside the working copy run `npm ci`, then `npm run dev`, and open the printed `http://127.0.0.1:...` URL in your browser. To preview the prebuilt snapshot immediately without building, serve `built/` over a local HTTP server. Direct `file://` opening is unsupported.
3. Gather your real brand or studio name, editorial headline (including which words should be italicized in `#6F6F6F`), supporting description, navigation links, CTA button label, and licensed background video (`MP4` encoded in H.264 `yuv420p`). Do not invent client names, metrics, or unverified claims.
4. When using an AI assistant (ChatGPT, Claude, Gemini), upload your working source files (`index.html`, `package.json`, `tailwind.config.js`, `src/App.tsx`, `src/index.css`, `src/styles/fonts.css`, `src/styles/theme.css`, `CUSTOMISE.md`) and describe your requested edit. Never share passwords, private API keys, or hosting tokens. Ask the AI to read the files first, keep the React + TypeScript + Tailwind stack intact, and return complete updated files at the same paths.
5. Update the page `<title>` and `<meta name="description">` in `index.html`, then update the brand mark (`Aethera®`), the `<h1>` headline (`Beyond silence, we build the eternal.`), and the supporting `<p>` description in `src/App.tsx`. Save and verify in the browser.
6. Update `NAV_ITEMS` (`Home`, `Studio`, `About`, `Journal`, `Reach Us`), the `"Begin Journey"` CTA buttons, and the inquiry modal copy (`Enter the sanctuary.`) in `src/App.tsx`. Connect `handleFormSubmit` to your real form endpoint or mailto handler.
7. To replace the looping background video, host your H.264 MP4 file (or place it inside `public/assets/`) and update `VIDEO_URL` in `src/App.tsx`. The `requestAnimationFrame` loop automatically reads `video.duration` to fade in over the first `0.5s`, fade out over the final `0.5s`, and wait `100ms` on `ended` before replaying from `currentTime = 0`.
8. Test at `1440×900`, `820×1180`, `375×812`, and `320×740`. Verify the staggered `fade-rise` animations (`0s`, `0.2s`, `0.4s`), smooth `0.5s` video fade transitions across loop boundaries, responsive navigation wrapping at `320px` with zero horizontal overflow, and keyboard `Escape` closing on the inquiry dialog.
9. Run `npm run build` (`tsc --noEmit && vite build`), then `npm run preview`. Upload the contents of `dist/` (with `index.html` at the root) to your static host (Vercel, Netlify, Cloudflare Pages, GitHub Pages, or S3/CloudFront). Note that `built/` in the ZIP is the initial prebuilt snapshot; always publish `dist/` after editing `src/`.
10. Keep a versioned backup of both your edited `src/` and built `dist/` for each release. If an edit introduces a layout or build regression, restore the last known-good file and re-run `npm run build`.

8. **Pre-launch QA & accessibility audit:** Audit my current `index.html`, `src/App.tsx`, `src/styles/fonts.css`, and `src/styles/theme.css` before launch. Guide me step by step through running `npm ci` and `npm run build`, configuring the output directory (`dist`), and verifying relative asset paths, HTTPS, and video playback on the live URL. 12. **Troubleshooting & bug diagnosis:** Ask me what behavior I expected, what actually happened, which browser/device I used, and any console or terminal error output.
