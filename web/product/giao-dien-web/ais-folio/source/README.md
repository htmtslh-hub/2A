# AIS Folio 1.0.0

A static visual-editor portfolio with a cyan/navy grid, original anime character, About Me, experience, six project studies, software list and email contact. All personas and project studies are fictional.

## Start
Read CUSTOMISE.md for the exact edit map, ten steps and twelve AI prompts. Extract all eight files; open index.html beside assets/. No installation, framework, build, API or network font required.

## Features
Navigation toggles with the menu button; Escape closes and returns focus. Mobile navigation closes on selection. Native details opens project descriptions with mouse or keyboard, including without JS. Finite scroll reveals default on under OS reduced motion. No infinite animation, account system, backend, PDF résumé, form submission or social integration. Example email opens an app only and must be replaced.

## Art and editing
assets/img/character.webp contains the transparent original character. assets/img/projects.webp contains a 3×2 poster sheet. Change text in index.html and tokens in assets/css/style.css. Images are generated using the built-in image generation tool; the reference screenshot is not included in the customer package. System fonts require no redistributed font licences.
