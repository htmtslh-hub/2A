# ASTRO Armor 1.0.0

Static fashion product template. Unzip the whole folder and open index.html. No install, build, remote fonts or API is needed.

## What is included
Read CUSTOMISE.md first: ten setup steps, twelve complete AI prompts and a counted editing map. Nine files: index.html; assets/css/style.css; assets/js/main.js; assets/img/armor-beige.webp; assets/img/armor-red.webp; assets/img/armor-reference.jpg; CUSTOMISE.md; README.md; LICENCE.txt.

Three-column ivory product stage, beige/orange jacket, four size choices, four colour previews, native size/search/account dialogs, favourite and local demo bag with removal/subtotal, mobile menu and finite scroll/entry motion. All state resets on reload. No authentication, stock, order processing or payments. The contact email is a reserved example address that must be replaced. No form sends data.

## Editing
Colours and system fonts are declared at the start of CSS. Text, metadata, native details and size table are in HTML. Unit price and interaction labels are also in JS. The unchanged supplied JPEG is displayed through local CSS crops for the beige hero and construction details. Two local transparent WebPs supply red and filtered black/white colour previews; alternate swatches are not separate product photography. Replace with permitted assets for a live business.

## Accessibility and verification
Semantic landmarks, skip link, labelled SVG controls, pressed states, focus outlines, native dialogs and keyboard-aware menu. Pause motion is session-only; default finite motion runs regardless of OS reduce. No-JS content and section links remain visible, but interactive selectors, dialogs and bag require JS. Browser verification status is documented in the project QA record; do not infer Safari or physical-device testing from a screenshot.
