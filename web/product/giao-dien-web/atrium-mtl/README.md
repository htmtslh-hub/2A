# ATRIUM MTL — An Archive of Light Cast in Stone (`atrium-mtl`)

**ATRIUM MTL** (`t53`) is an editorial museum and brutalist architectural photography archive landing page featuring a floating white header card, oversized `Archivo` 900 display typography, a 3-to-6-column opposing infinite mosaic (`14.6s` loop) of monochrome photography and grain-textured primary color blocks, a 2.1s WAAPI load entrance choreography, and five responsive layout modes (`desk`, `tab-l`, `tab-p`, `mob-l`, `mob`).
