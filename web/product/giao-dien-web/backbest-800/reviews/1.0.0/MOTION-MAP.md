# BackBest 800 motion map

Image-only reference (`media_1792074878844_0322ecdc.png`). Modest inferred motion preserves the initial `1440×822` hero composition. Product Owner policy (05/10/2026): motion defaults ON in all browsers on every page load, including when OS `prefers-reduced-motion: reduce` is active or stale `localStorage` values (`motion=off`, `backbest-800-motion=off`) exist; `#motion-toggle` pauses/resumes motion for the current visit only and resets to ON upon reload. Zero idle `requestAnimationFrame` loops.

| Motion | Trigger & timing | Fallback & cleanup |
|---|---|---|
| Headphone introduction | Initialisation `900ms`, `opacity 0.15 → 1`, `translateX(-48px → 0)` | Finite RAF `Map` entry removed on completion; any finish transition cancels intro immediately. Static headphone visible without JS. |
| Finish transition (`BLACK / WHITE / RED`) | `720ms` directional exit (`0–44%`), image/swatch/index swap at `44%`, cubic-out enter (`44–100%`) via `[data-color]`, `#finish-select`, `#hero-next` / `[data-step]`, `ArrowLeft`/`ArrowRight`, or horizontal pointer swipe | Dedicated `.headphone-motion` wrapper `transform` and `opacity`; actual `.webp` source swaps (`headphone-black.webp`, `headphone-white.webp`, `headphone-red.webp`). Cancels prior RAF frame, wraps both directions (`0↔2`), rapid clicks settle cleanly. Independent of CSS transitions/WAAPI. |
| Soundstage preview sequence | `#action-open` opens `#action-dialog` and runs a `4200ms` finite timeline across all 3 headphone finishes with progress bar and stage captions | Explicitly labelled an animated colourway sequence, not video footage. Finite RAF stops on dialog close, `Escape`, backdrop click, `document.hidden`, or Pause motion; `#action-replay` restarts from `0`. |
| Editorial scroll reveal | `IntersectionObserver` (`threshold: 0.1`), `650ms` cubic-out `translateY(24px → 0)` | Runs once per `[data-reveal]` element via finite RAF; text remains `opacity: 1` for immediate readability under all modes. Cancelled and reset to `transform: none` on Pause motion. |
| Acoustic chamber engineering scene | Real `scroll` and `resize` events, progress clamped `0–1` (`--scene`) | Single scheduled RAF per event (`scrollFrame = 0` after paint); reversible headphone glide `translateX(-4% → 4%)` and progress rule fill; recomputes on mobile/resize; neutralised when motion is paused. |
| Status toast | Configuration / bag action, `3200ms` timer | `clearTimeout` cancels prior timer; announces real local state changes via `role="status"`. |

Desktop (`>860px`) displays the top-left 4-link category navigation bar (`PHONE`, `→ HEADPHONE`, `LAPTOP`, `SPEAKERS`) and bottom-left `.chapter-open` index trigger matching the reference; mobile/tablet (`<=860px`) collapses `#main-nav` behind `.menu-toggle` (`aria-expanded`, `Escape` closes and restores focus, hidden links excluded from Tab order, `resize` resets menu state). Native `<dialog>` modals restore focus to their opener on close. Native `<details>` accordions operate without JS.
