# BeetBuh 1.0.0

Read CUSTOMISE.md first: ten steps, twelve complete AI prompts and a counted edit map. Extract all nine files and open index.html beside assets/. Plain HTML/CSS/JavaScript, three local WebP images, no framework, install or build.

## Working behaviour
Three hero states: upright product, alternate open angle and an explicitly labelled earcup close-up crop. This is image switching, not a 3D viewer or three different colour finishes. Previous/next, state dots, arrow keys and horizontal pointer swipes work. Finite animations cancel rapid prior input. Mobile menu closes on links, Escape and desktop breakpoint. Product image expansion opens a real native dialog and restores focus when closed. Native specification disclosure works without JS. Explore Now and Learn More link to actual sections. Shop Now leads to an explicitly labelled enquiry section; email opens your mail app and never submits or places an order.

Scroll reveals and entry/view transitions use finite requestAnimationFrame with no idle loop. Motion defaults ON including OS reduce and old saved-off states, per the product policy. Pause motion applies to this page visit only; reload restores ON. No JS retains content, navigation, email and specifications and hides JS-only controls. Missing images preserve text and actions. Relative paths support file:// and static hosting, including slashless demo routes.

## Artwork, fonts and demonstration scope
BeetBuh is an independent fictional headphone interface concept. Product render geometry, orange finish, material/connectivity/battery/sound/folding copy and the campaign model are illustrative, not verified manufacturer claims or a real endorsement. Replace them with verified business information. hello@beetbuh.example is a demo contact. No account, payment, live inventory, music playback, audio measurements, tracking or backend is included.

headphone-hero.webp is the upright angle, headphone-angle.webp the open angle, listener.webp the fictional lifestyle cutout. Preserve transparency, full product silhouette and square canvas when replacing. Optional Google Fonts load Bebas Neue and Permanent Marker with display=swap; system fallback fonts work offline but will not look identical. Sources/licences are in LICENCE.txt. No font files are bundled. A separate brush face is intentional to match the reference typography.
