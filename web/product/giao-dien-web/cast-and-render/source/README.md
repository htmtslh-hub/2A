# Cast & Render — 3D Object Studio (`v1.0.0`)

Single-file scroll-scrubbed video landing page (`index.html`) for **Cast & Render**, a fictional 3D object & surface-shader studio at No. 112 Render Lane. Scrolling scrubs an all-intra 1080p studio video frame by frame while three editorial text panels cross-fade in and out over a warm paper wash (`#f2f0ec`) and SVG fractal-noise grain.

## Included Files

- `index.html` — Self-contained HTML5 page (single `<style>` in `<head>`, single IIFE `<script>` at the end of `<body>`, zero external JS/CSS frameworks)
- `CUSTOMISE.md` — 10-step customisation guide + 12 copy-ready AI prompts
- `README.md` — Quick-start instructions and architecture overview
- `LICENCE.txt` — Commercial and client website usage licence

## Quick Start

1. Extract `cast-and-render.zip`.
2. Open `index.html` directly in any modern browser or serve via a local static server (`npx serve .` or `python -m http.server 8080`).
3. Scroll down and up to scrub the 241-frame studio video, use the bottom chapter scrubber (`01 Queue`, `02 Mesh`, `03 Surface`), or click `Works`, `About`, `View the reel`, `Tour our space`, and `Start a brief` to open the interactive Studio Sheet modal.
