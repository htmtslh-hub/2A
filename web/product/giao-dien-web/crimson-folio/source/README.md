# Crimson Folio

An editorial portfolio for an independent UX/UI designer. Version 1.0.1.

## Getting started

Read CUSTOMISE.md for the ten-step editing workflow and twelve AI prompts.
Extract the entire package and open index.html. Keep assets next to it.
No installation, build, framework or external font is required.

## Included

CUSTOMISE.md is the guide to editing this specific template.
The core files are index.html, assets/css/style.css, assets/js/main.js,
CUSTOMISE.md, README.md and LICENCE.txt. Two supplied local WebP images
are retained as the requested exception to the standard six-file package.

Navigation, section links, a mobile menu, finite scroll reveals and an email
link are included. No backend, payment processing, booking, working contact
form or client projects are included. All project concepts and Mira Arden
are fictional. Replace hello@example.com before publishing. Two genuine QR
codes encode mailto links to this demo email, with different subject lines.
Regenerate both QR artworks when changing the email; changing only their
surrounding links does not update the encoded destination.

Colours and system font stacks are at the beginning of assets/css/style.css.
Project mockups are original HTML/CSS and inline SVG compositions. They are
static artwork rather than interactive websites. The portrait path is
assets/img/mira-portrait.webp; the 3D avatar is assets/img/mira-avatar.webp.

## Access and motion

Semantic headings, visible focus, a skip link and mobile menu keyboard
behaviour are implemented. Animations run by default, including when the
operating system requests reduced motion, as required by the product owner.
They finish after 550 ms; no repeating motion is included. All content remains
visible without JavaScript. System font fallback makes the site independent
of font downloads. Browser verification is recorded in the internal QA report;
this revision was checked through file:// on installed Chrome, Edge and
Coc Coc at 1440, 820, 375 and 320 CSS pixels, including offline and no-JS.
Firefox, Safari and physical devices have not been verified. Desktop 200%
reflow was simulated with a 720 CSS-pixel viewport.

This source revision is for visual review, not a commercial release. The
existing crimson-folio.zip contains the previous version. A replacement ZIP
is pending approval of the larger image package size and final image rights.
