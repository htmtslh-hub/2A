# Cyber Ronin customisation guide

This guide takes you from the downloaded ZIP file to a website you can publish. Follow the steps in order the first time. Every AI prompt below is complete: copy it and attach the current files. If you have not supplied a bracketed business detail, the AI must ask you for that missing information before making dependent edits.

The three backgrounds are hero-base-img, hero-reveal-img and product-thumb. Preserve their paired cover/position rules; changing only one hero photograph breaks alignment. The product thumbnail is a decorative background. Meaningful replacement images need suitable text alternatives.

The Main core, Vision and Force icon buttons and Reserve Now have no business action in this demo. Ask for your approved URL or remove the control; do not invent a successful reservation. The specs and names are fictional and must be replaced with verified product information before selling a real product.

Keep the 120/160/260px mask radius rule and relative getBoundingClientRect coordinates. The heading splitter uses dataset.split and continuous word indexes. Preserve no-JS, observer and reduced-motion fallbacks. Any full-file replacement must retain both inline <style> and <script>.

## Runtime and publication

Keep a single index.html with inline CSS/JS; no framework or build. Open index.html directly. Remote images/fonts require internet. Publish only index.html plus any local assets you deliberately add.

For every prompt: ask for missing business data; never invent facts, URLs or success. Edit only an authorised working copy. Return complete changed files with exact paths, update documents and literal counts, state actual checks/limits, and do not publish or alter DNS unless requested.

## Step 1 - Extract and open

Extract the whole ZIP. Read README.md and LICENCE.txt. Use the opening instructions below; confirm the demo appears before editing.

## Step 2 - Create a backup

Keep the ZIP unchanged. Copy the extracted folder to website-working-copy. Back up before each major edit, outside the publication folder. Use a plain text editor and UTF-8; avoid accidental .txt extensions.

## Step 3 - Prepare verified information

Collect brand, audience, offer, language, authorised assets, contact details and real action destinations. Say “not decided” if needed, but resolve unsupported demo claims before business publication.

## Step 4 - Work with AI

Attach the latest complete source ZIP or the current source files plus customer documents. Screenshots explain appearance but do not replace source. In every new chat, send current files and Prompt 01 again. Never share secrets or private customer data.
