# Cyber Ronin 1.0.0

Read CUSTOMISE.md first for the editing map, ten-step workflow and twelve ready-to-copy AI prompts.

A static cyberpunk product hero with cursor/touch spotlight revealing an alternate scene, staggered typography, a glass product card and an operative-specifications block. Suitable for concept showcases and visual product introductions.

## Open

Extract the complete ZIP and open cyber-ronin/index.html in a modern browser. No installation, build, framework or local server is needed. The executable website is one self-contained HTML file with inline CSS/JavaScript; README.md, CUSTOMISE.md and LICENCE.txt are customer documents, not runtime dependencies.

Images load from the exact supplied images.higgs.ai/CloudFront URLs; Orbitron-Medium loads through OnlineWebFonts and Inter through Google Fonts. Internet access is required for the supplied photography and fonts. Offline fallback text remains available, but artwork is unavailable and typography changes. No photo/font files are bundled.

## Included behaviour

- Desktop and phone compositions with the supplied breakpoints.
- Mouse/touch circular mask, responsive radius and two background scenes.
- Heading word stagger and observed one-time reveals.
- Reduced-motion, no-IntersectionObserver and no-JavaScript visible-copy fallbacks.

The three icon buttons and Reserve Now are presentation controls from the approved brief. They do not switch product modes, collect reservations or process payment. No checkout, account, inventory, tracking, contact form or backend is included. Connect your own real destinations before using the template to sell anything. All names and specifications are fictional demo copy.

## Edit

Everything visual is in index.html: CSS tokens in :root, styles in <style>, content in <main>, behaviour in the bottom <script>. See CUSTOMISE.md for exact strings and counts. Keep both background layers aligned and preserve mask coordinate calculations. Replace the paired images together when using a different scene.
