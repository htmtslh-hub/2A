# Digital Epoch — Decentralized Web Foundation & Ecosystem Hero

**Digital Epoch** (`digital-epoch`, v1.0.0) is a single-file, high-craft light-mode Web3 & enterprise ecosystem landing page built with plain HTML5, CSS3, and vanilla JavaScript — zero frameworks and zero build steps required.

## Quick Start

1. Extract all 4 files (`index.html`, `CUSTOMISE.md`, `README.md`, `LICENCE.txt`) into a folder.
2. Open `index.html` directly in any modern browser or serve it via a local static HTTP server (e.g., `npx serve .`).
3. Follow `CUSTOMISE.md` for the 10-step customisation guide, 12 AI prompts, and verified literal string counts.

## Key Features

- **48px Rounded Hero Container & Video Stage:** `1400px` max-width white frame (`600px` tall) with a `scale(1.05)` looping 3D architectural video background (`74f9b798-3f00-4e86-8a01-377aa16ffeaa.mp4`), `Outfit` display typography (`#0a1b33`), and `#0a152d` pill CTA.
- **Floating Frosted Bottom Navbar:** Centered `backdrop-filter: blur(24px)` pill navigation featuring a `✦` motion pause/resume button, `Products`, `Docs`, and `Get in touch ›` pill button.
- **Seamless Dual-Set Partner Marquee:** Infinite CSS `@keyframes marqueeScroll` (`0 → -50%`) with edge fade masks and `8` partner cards (`Procure`, `Shopify`, `Blender`, `Figma`, `Spotify`, `Lottielab`, `Google Cloud`, `Bing`) that reveal full-bleed color gradients and inverted white logos on hover.
- **Modular Architecture Inspector & Partner Modal (+15–20% Creative Enhancements):** Interactive 3-tab protocol telemetry & SDK code switcher (`01 Core Protocol`, `02 Builder SDK`, `03 Enterprise Mesh`) plus an accessible partner inquiry dialog (`#epochModal`).
