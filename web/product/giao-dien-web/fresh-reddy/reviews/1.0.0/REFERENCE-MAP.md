# Reference map
Header → .site-header; logo nghiêng trái, bảy liên kết bên phải.
Hero headline → .hero__copy, .heart; ba dòng, hai CTA viền.
Ba cốc → SVG .coffee-scene; gradient, pattern hạt, nhãn đỏ. Bản vẽ tái tạo không phải render 3D gốc.
Signature → .hero__signature; dots → section anchors.
Bottom → .hero__bottom, mouse cue, community anchors, prev/next section anchors.
Các section #about, #services, #equipment, #culture, #tasting, #contact: nội dung bổ sung suy ra; không có ảnh tham chiếu.
Mobile: bố cục dọc, menu đóng/mở; không có reference mobile.
