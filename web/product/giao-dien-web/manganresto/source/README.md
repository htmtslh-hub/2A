# Manganresto 1.0.0

Read CUSTOMISE.md first: ten steps, twelve complete AI prompts, and a counted edit map. Extract all files and open `index.html` beside `assets/`. Built with pure HTML/CSS/JavaScript, local transparent WebP imagery, no framework, no install or build steps required.

## Working Behaviour
Manganresto features an organic dual-tone split hero layout (charcoal and warm golden yellow) with a centerpiece gourmet pasta plate framed by halo orbits, interactive mini dish cards, and culinary metric badges. Key interactions include:
- Fully accessible mobile hamburger drawer with ARIA states (`aria-controls`, `aria-expanded`), keyboard focus trap, and Escape key dismissal.
- Menu category tab filters (All Dishes, Breakfast, Appetizers, Handcrafted Pasta, Chef Specials) with smooth state transitions.
- Interactive search dialog modal with live dish query filtering, accessible dialog semantics, and keyboard shortcuts.
- Interactive dish ordering notifications and table booking inquiry form with native input validation and real-time confirmation status.
- Desktop hero plate micro-motion and kinetic perspective tilt with finite `requestAnimationFrame` and smooth spring dampening.
- Fixed vertical floating social media dock with accessible labels.
- Skip link for screen reader and keyboard accessibility, valid semantic landmarks, and WCAG AA color contrast.

Motion defaults ON across all browsers including Edge and Cốc Cốc per product policy, with graceful fallbacks. Relative asset paths support `file:///` local browsing as well as static server deployments.

## Artwork, Fonts and Demonstration Scope
Manganresto is an independent fine-dining culinary showcase template. Dish names, prices, chef bios, and reservation endpoints are illustrative demonstrations. Replace them with your restaurant's authentic business details before publishing.

Images:
- `hero-plate.webp`: Signature black squid ink tagliatelle and garlic prawn pasta on a white porcelain rim plate with transparent background.
- `dish-breakfast.webp`: Healthy poached egg and avocado toast with heirloom tomatoes and seeds on a round ceramic plate with transparent background.
- `dish-appetizer.webp`: Artisanal burrata and black mission fig salad with pomegranate pearls on a round ceramic plate with transparent background.

Optional Google Fonts: Plus Jakarta Sans and Playfair Display with `display=swap`. System fallback fonts are declared for seamless offline browsing.

## Editing
Customise color tokens at the top of `assets/css/style.css`, content and dishes in `index.html`, and menu data in `assets/js/main.js`. Refer to `CUSTOMISE.md` for complete step-by-step editing instructions and AI prompts. Read `LICENCE.txt`.
