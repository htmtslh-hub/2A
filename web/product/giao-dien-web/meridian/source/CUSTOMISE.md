# Customise Meridian

## Editing map

| File | Literal | Count | What it controls |
|---|---|---:|---|
| index.html | `<title>` | 1 | Browser title |
| index.html | `href="#` | 9 | Demo/section links |
| index.html | `<video` | 1 | Background media |
| index.html | `aria-label=` | 3 | Accessible names |
| index.html | `Meridian` | 4 | Brand occurrences |

CSS tokens are in :root. The original brief keeps inline code except Mostar (styles.css/script.js). Changing only a starting CSS custom property may not affect values later written by JavaScript. The bundled H.264/yuv420p video replaces the original HEVC clip with the owner's explicit approval on18Oct2026. Keep assets/video beside the HTML.

## Step 1 — Unzip and open

Extract the whole ZIP and open index.html. Confirm the interface and keep all relative assets.

## Step 2 — Make a backup

Keep the original ZIP untouched; copy the whole extracted folder before editing. Work only in that copy.

## Step 3 — Prepare your information

Collect verified brand, audience, copy, real contact/link targets and licensed assets. Mark undecided facts; do not invent them.

## Step 4 — Work with AI

Send the latest runtime files, README, CUSTOMISE and LICENCE; use Prompt01. If the AI cannot edit directly, replace files with its complete returned versions. Start a new chat by resending current files.

## Step 5 — Replace demo content

Use Prompts02/03. Replace or clearly retain demo information and connect real destinations. Refresh and click each action.

## Step 6 — Adjust the appearance

Use Prompts04–07 for colour, fonts, imagery, language or sections. Preserve responsive behaviour and update the editing map.

## Step 7 — Test the final version

Use Prompt08; check desktop/tablet/phone, keyboard, video, menu, zoom, offline and motion. Record actual tests and unresolved problems.

## Step 8 — Publish when authorised

Use Prompt09 and current host documentation. Upload only runtime files and required licence notices, not ZIP backups or private notes. Verify the public URL.

## Step 9 — Optional custom domain

Use Prompt10, actual DNS values and a backup of records. Preserve email records and verify HTTPS/www.

## Step 10 — Update and recover

Use Prompts11/12. Keep all changed files on the same version, test locally and update the same hosting project. Restore the known-good backup if necessary.
