# Mint Atlas 1.0.0

An editable static character dossier for original-world creators, illustrators and game concept portfolios. Mint-and-slate palette, a transparent anime explorer rising above the hero, native ability cards, a character score chart and two artwork portraits.

## Open and customise

Extract the entire ZIP. Open `mint-atlas/index.html` in a modern browser with `assets/` beside it. No installation, build or account required. Read CUSTOMISE.md: the product edit map, ten setup steps and twelve complete AI prompts describe exact files and replacements. Six core files plus three local800×1200 WebP assets are included. Private original PNGs, design references and QA are excluded.

## Real interactions and demo content

Navigation and mobile menu work with keyboard, Escape and focus return; menu state resets when resizing. Abilities use native details/summary and work without JavaScript. Story/statistics links target real sections. Gallery links open full local WebP images; use browser Back to return. Contact opens your mail app using the sample hello@example.com address; replace it before publishing.

Mira Vale, The Quiet Frontier, abilities, rank and scores80/92/68/75 are fictional concept content, not real game data. The three marker lines are decorative, not a carousel. Stars and circles are decorative. No login, search, accounts, favourites, chat, game installs, payments, backend, tracking or data submission is provided.
