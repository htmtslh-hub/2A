# Monoframe (`monoframe`)

Full-screen creative agency hero landing page built with React 18, TypeScript, Vite, and Tailwind CSS (renamed from the `"Mainframe"` specification per product owner instruction).

- **Source directory:** `source/` (`index.html`, `src/App.tsx`, `src/main.tsx`, `src/index.css`, `public/assets/hero-h264.mp4`, `CUSTOMISE.md`, `README.md`, `LICENCE.txt`, `THIRD-PARTY-LICENSES.txt`)
- **Production build:** `source/dist/` (generated via `npm run build`)
- **Customer archive:** `monoframe.zip` (contains editable source files + `built/` snapshot, excluding `node_modules` and `dist`)
- **QA & evidence:** `reviews/1.0.0/` (`BRIEF.md`, `QA.md`, `check.cjs`, `checks.json`, and multi-browser screenshots)
