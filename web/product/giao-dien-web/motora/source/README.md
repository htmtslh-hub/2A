# Motora 1.0.0

An automotive design-study template inspired by the supplied light configurator reference. Open CUSTOMISE.md first: it contains exact edit locations, ten steps and twelve complete AI prompts. Keep all eight files together and open index.html beside assets/. No build, framework, library, account, API or external font is needed.

## What is included
Six core files plus two generated WebP images: assets/img/coupe.webp (transparent vehicle cutout) and assets/img/interior.webp (cabin study). The store recording is outside this ZIP. Relative paths work through file:// and static HTTP hosting.

## Working interactions
Five finish previews with finite directional transitions, previous/next wrap and arrow keys; five detail categories; four vehicle hotspots and five specification cards; native information/configuration/search dialogs; one-model search and empty state; wheel preference in the enquiry summary; configuration saved in memory for this visit; mobile menu and Escape/focus; native specification accordions; finite reveals and a scroll-linked cabin image. Enquiry opens an email app, not a submitted order. Wheel selection updates the summary, not the image geometry. Exterior finishes use CSS colour filters on one original image and are visual approximations.

Motion defaults ON at every opening, including OS reduced motion and previous saved-off values. Pause motion stops finite timelines and shows revealed content for this visit only. There is no idle requestAnimationFrame loop. No JavaScript: the gold car, static specification cards, accordions, navigation, contact and all editorial content remain readable; dynamic controls are hidden. Missing artwork leaves text and contact actions available. No network dependencies or font downloads.
