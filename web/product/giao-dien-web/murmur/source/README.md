# murmur — Daily Murmur Podcast Landing Hero

A self-contained, single-file, one-screen landing hero for **murmur** (*"Daily Murmur Podcast"*), built with plain HTML5, CSS3, and vanilla JavaScript with zero frameworks and no build step.

## Files Included

- `index.html` — Complete self-contained markup, styles, and scripts (1440×900 cover-scaled frame `--u = max(100vw/1440, 100vh/900)`, 16:10 rainy apartment window background plate + mirror-padded 16:9 looping video at `111.11%` width / `left -5.556%`, screen-blended city bloom and headlight sweep lighting layers, `Newsreader 500` wordmark + `Inter` + `IBM Plex Mono`, deep navy glass player card `623.5×190` with 62-bar breathing waveform, Web Animations entrance timeline, and responsive `<= 820px` phone layout).
- `CUSTOMISE.md` — 10-step customisation guide and 12 AI prompts.
- `LICENCE.txt` — Commercial and client use licence.
- `README.md` — Quick-start instructions.

## Quick Start

1. Extract all 4 files from `murmur.zip`.
2. Open `index.html` directly in any modern browser, or serve the folder over a local static server (`npx serve .` or `python -m http.server 8080`).
3. Follow `CUSTOMISE.md` to replace the podcast title, cover artwork, episode metadata, waveform profile, or background video.
