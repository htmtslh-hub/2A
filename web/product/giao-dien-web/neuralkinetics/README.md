# NeuralKinetics (`neuralkinetics`) — Minimal Black-and-White Video Hero Landing Page

- **Mã sản phẩm (Catalog ID):** `t77`
- **Slug:** `neuralkinetics`
- **Phiên bản:** `1.0.0`
- **Danh mục:** Thương mại điện tử (`commerce` — Digital Banking Card & Adaptive Bionics)
- **Gói truy cập:** `free`
- **Công nghệ:** React 19 + TypeScript + Vite 6 + Framer Motion (`motion/react`) + `lucide-react` + Plain CSS (không dùng Tailwind) + Google Font `Inter` (`300`, `400`, `500`, `600`) kèm bản dựng tĩnh `source/built/`

## Cấu trúc sản phẩm trong kho lưu trữ

- `source/`: Mã nguồn hoàn chỉnh + tài liệu bàn giao (`CUSTOMISE.md`, `README.md`, `LICENCE.txt`, `THIRD-PARTY-LICENSES.txt`) + bản dựng tĩnh `built/`.
- `neuralkinetics.zip`: Gói bàn giao khách hàng được đóng gói và kiểm định tự động qua `tools/dong-goi.mjs neuralkinetics --ngoai-le`.
- `reviews/1.0.0/`: Hồ sơ nghiệm thu gồm `BRIEF.md`, `QA.md`, `check.cjs` và `checks.json` trên 4 trình duyệt (Chromium, Firefox, Edge, Cốc Cốc).
