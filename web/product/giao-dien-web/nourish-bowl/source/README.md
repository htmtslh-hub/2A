# Nourish Bowl — 1.0.0 local candidate
A navy-and-teal healthy-food website inspired by the supplied reference.

## Open and customise
Read CUSTOMISE.md first: ten steps, twelve prompts and a literal edit map. Open index.html directly or serve this folder with a static server. No installation, framework, build or runtime API. Keep all assets beside HTML.

Eight source files: index.html, assets/css/style.css, assets/js/main.js, assets/img/blue-fruit-bowl.png, assets/img/fruit-serving-platter.png, README.md, CUSTOMISE.md and LICENCE.txt.

## Included
Responsive menu, section links, finite load/scroll reveals and three native details panels for bowl ingredients. No order, checkout, login, live availability or message submission service. Sample email is a mailto link. Nourish is an illustrative identity, not an affiliation with an existing food business. The English copy was independently authored because the screenshot lettering is not clearly readable. No verified nutritional or health claims are included.

## Images and fonts
Two food cutouts were generated with built-in imagegen using the supplied image as composition reference, stored locally as transparent PNGs. The source screenshot itself is not embedded. Decorative SVG leaves/CSS berries are local. No network font; system font stacks vary by OS. CSS variables control colours and type. Preserve PNG transparency when customising.

## Motion and verification
Finite RAF reveals default ON under OS reduced motion per owner policy. No perpetual animation. Without JS, content/navigation/ingredient details remain visible. See ../reviews/1.0.0/ for actual browser checks and release limitations. No claims of testing Safari, physical devices, Edge or Cốc Cốc. This is a local candidate; no commercial ZIP/catalogue/deployment.
