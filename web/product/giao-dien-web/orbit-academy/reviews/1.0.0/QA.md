## Manual resolutions for older checker
Absolute external NASA URLs receive null from structure() and are counted as bad by its `!link.ok` predicate without any external request. SCIENCE-SOURCES.md records successful primary-page verification. This does not mean HTTP errors were ignored.
The menu test assumes the mobile toggle disappears and the nav stays visible on desktop. This screenshot-led product uses an always-visible Menu pill and collapsible navigation at every width. Test-motion verifies open/Escape at all four widths; resize closes the menu and leaves the toggle available. That resetOnDesktop assumption is not applicable to this menu model.
The old reduced-motion check expects every below-fold reveal already visible. The newer project's 05/10 rule mandates motion ON even under OS reduce, so false/allVisible and zero idle animations are expected. Actual midframes, scroll, pause and reload are verified under reduce. No shared checker/rules were edited; no source functionality was suppressed to make old assertions pass.

## Interactions and limits
Section links/subject cards and sources work without JS. Menu/arrows/01–03/swipe update the actual world. Search filters exactly three on-page paths. Lessons provide source-linked explanations and one local knowledge question each, with feedback and unique correct-check progress held only in memory. Reset and reload clear it. Guide icon opens text instructions, not video. Contact uses reserved .example email requiring replacement. No grades backend, LMS, credentials, enrolment, certificates, tracking or payment service. Concept pictures are imaginative, not scientific scale models/NASA archival photos.
