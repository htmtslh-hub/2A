# Orbit Academy 1.0.0

An independent astronomy education template for learners and educators. Original cinematic concept imagery, three learning worlds, Earth/planet/meteor lesson summaries, native lesson dialogs and local knowledge checks. No NASA affiliation or endorsement.

Start with CUSTOMISE.md: exact edits, ten steps and twelve complete AI prompts. Extract all ten files and open index.html next to assets/. No install, build, network font, API or account is required.

## Package
index.html; assets/css/style.css; assets/js/main.js; four images in assets/img/ (earth-world.webp, planet-world.webp, meteor-world.webp, objects.webp); CUSTOMISE.md; README.md; LICENCE.txt.

## Working
Menu, three-scene directional carousel with arrows/keyboard/swipe, three-subject local search, lesson dialogs with one question per path and explanatory answer feedback, session-only progress/reset, learning-guide dialog, local anchors, external science sources and a demo email link. The play icon opens text guidance; no video is bundled. A sticky scroll scene and reveals respond to real scrolling. Pause motion is session-only and defaults ON after reload even under OS reduced motion. No-JS retains all static educational content and links.

## Not bundled
No LMS, accounts, certificates, backend, enrolment, billing, remote search, tracking, grade storage or working email service. hello@orbit-academy.example must be replaced. Menu art is imaginative, not NASA archival imagery or accurate scale models. Science is introductory: sources are linked beside each lesson and were checked on 13/10/2026.

## Edit
Update HTML and the worlds/lessons arrays in JS together. Colours/fonts live in CSS :root. Keep all images local. CUSTOMISE explains the equal-third object sprite, image crops, scientific verification and correct-answer indexes.
