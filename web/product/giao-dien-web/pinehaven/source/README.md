# Pinehaven — static cabin retreat website template

Version 1.0.2 · Forge Zone · custom image-led exception to WEB-STATIC-1 (standards 1.2)

Start with **CUSTOMISE.md**. It has the exact edit map for this template, a ten-step setup path and twelve copy-ready prompts for an AI assistant.

## Open and use

Extract the entire ZIP, then open `pinehaven/index.html` in a current browser. No build, framework, account or script installation is needed. Keep `assets/css/style.css`, `assets/js/main.js` and all three files in `assets/images/` at their relative paths. To publish, upload the contents of the extracted `pinehaven` folder to a static web host.

## Included

- One English landing page for a fictional forest cabin retreat.
- A full-width cabin-photo hero, responsive navigation, a featured-stay information card, cabin and setting sections, experience highlights, and an email enquiry route.
- Three original AI-generated local WebP photographs: the forest cabin, interior and trail. They are bundled in the ZIP, with no image hotlinks.
- One CSS file, one small JavaScript file, this README, CUSTOMISE.md and LICENCE.txt.

The navigation toggle is the only JavaScript-dependent feature. The full page and links remain visible without JavaScript. No web font, image CDN or third-party script is required.

## Important demo limits

Pinehaven, Evergreen Pine Lodge, the setting, guest capacity and `$295 / night` are fictional demonstration content. The rate is expressly marked illustrative. The address `stays@pinehaven.example` is a placeholder; it will not receive booking enquiries. Replace it with your actual reservation or contact channel before publishing.

The card is an enquiry route, not a booking engine. This template does **not** include live availability, date selection, reservations, payments, forms, customer accounts, analytics or a backend. The generated images depict an imagined property and must be replaced if they do not represent the real property being advertised.

## Local artwork and template standard

This package intentionally departs from WEB-STATIC-1 W01, W03 and W06 to satisfy the requested photographic design. It has nine files rather than six, includes three local bitmap images rather than inline SVG-only artwork, and is larger than 20,480 bytes. The HTML/CSS/JS structure, relative paths and offline operation remain unchanged.

The photographic assets were created for this template through the built-in image-generation tool. Small decorative tree marks are inline SVG. No photo, logo or testimonial from the reference image was copied.
