# prmpt (`prmpt`) — Scroll-Driven Fashion & Archive Landing Page

- **Mã sản phẩm (Catalog ID):** `t71`
- **Slug:** `prmpt`
- **Phiên bản:** `1.0.0`
- **Danh mục:** Thương mại điện tử (`Fashion & Archive Scroll Showcase`)
- **Gói truy cập:** `free`
- **Công nghệ:** React 19 + TypeScript + Vite 6 + Tailwind CSS v4 + GSAP 3.15 (`ScrollTrigger`) + Motion 12 (kèm bản dựng tĩnh `source/built/`)

## Cấu trúc sản phẩm trong kho lưu trữ

- `source/`: Mã nguồn hoàn chỉnh + tài liệu bàn giao (`CUSTOMISE.md`, `README.md`, `LICENCE.txt`, `THIRD-PARTY-LICENSES.txt`) + bản dựng tĩnh `built/`.
- `prmpt.zip`: Gói bàn giao khách hàng được đóng gói và kiểm định tự động qua `tools/dong-goi.mjs prmpt --ngoai-le`.
- `reviews/1.0.0/`: Hồ sơ nghiệm thu gồm `BRIEF.md`, `QA.md`, `check.cjs` và `checks.json` trên 4 trình duyệt (Chromium, Firefox, Edge, Cốc Cốc).
