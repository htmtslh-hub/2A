# Puro Amor — 1.0.0 local candidate
A Portuguese coffee campaign interface inspired by the supplied visual reference.

## Open and customise
Read CUSTOMISE.md first for ten editing steps, twelve complete prompts and a measured edit map. Open index.html directly, or serve this folder with a static server. No installation/build. Keep assets/css/style.css, assets/js/main.js and assets/img/coffee-splash-transparent.png alongside the page. This candidate has seven files including README.md, CUSTOMISE.md and LICENCE.txt.

## Included behaviour
Responsive navigation, keyboard Escape/focus, section anchors, native manifesto popover, finite hero entrance and scroll reveals. The search-shaped link navigates to the drink menu. Profile and Card are illustrative; there is no account, stored balance or loyalty system. No video was supplied; the manifesto panel explicitly provides text instead. Cards describe coffee styles, not verified local availability/prices. Contact uses a sample mailto link.

## Assets and motion
Hero art was generated with the built-in imagegen tool using the user screenshot as composition reference. It is an RGBA transparent PNG, stored locally; there are no network assets/fonts or runtime API calls. Brand seal is an approximate inline SVG. System fonts can vary by OS. Owner policy keeps finite motion enabled under OS reduced motion; no perpetual loops.
