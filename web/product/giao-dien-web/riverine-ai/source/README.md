# riverine.ai — 1.0.1

Read CUSTOMISE.md first for the editing map,10steps and12AI prompts.

A regenerative AI river-video hero with tree-and-moth SVG branding, responsive navigation and a single WAAPI entrance. One HTML; RV fonts are not included and use the specified fallbacks. Anchor links and sound control are visual demo elements.

## Open
Extract the entire ZIP, then open index.html. Keep all relative files beside it. No build or framework is required. Runtime files: `index.html`.

RV fonts were not supplied. The requested @font-face declarations intentionally remain; the specified system fallbacks are used. Missing RV requests are documented, not bundled as fake fonts.

## What is included
A static interface and its documented local interactions. Demo anchors/dialogs do not provide enrolment, AI services, billing, booking, forms or payment. External media, fonts, and the FENNEC model/Three.js require a network connection.

## Verification
Windows headless Chromium153 and Firefox155 were used for layout checks; production verification is recorded separately. Safari, physical phones and every accessibility condition have not been certified. Read the product description before choosing this design.

## Editing
Brand, copy and links are in index.html; inline styles/scripts remain inside it except Mostar's styles.css/script.js. Keep all scene layers, breakpoint rules and SVG paths unless intentionally redesigning. Restore a backup if a change breaks the page.
