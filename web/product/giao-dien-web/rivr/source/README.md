# RIVR — Fluid Asset Streams & Smart Vaults DeFi Hero

**RIVR** (`rivr`, v1.0.0) is a single-file, glassmorphic DeFi liquid staking and smart vault dashboard hero built with plain HTML5, CSS3, and vanilla JavaScript — zero frameworks and zero build steps required.

## Quick Start

1. Extract all 4 files (`index.html`, `CUSTOMISE.md`, `README.md`, `LICENCE.txt`) into a folder.
2. Open `index.html` directly in any modern browser or serve it via a local static HTTP server (e.g., `npx serve .`).
3. Follow `CUSTOMISE.md` for the 10-step customisation guide, 12 AI prompts, and verified literal string counts.

## Key Features

- **3rem Glassmorphic Video Stage:** Full-viewport `#f0f0f0` frame housing a `1536px` rounded container with a looping 3D fluid wave background video (`4286c423-2fd9-4efd-92bd-91a939453fc1.mp4`) and `Helvetica Regular` typography (`#5E6470`).
- **Faux-Cutout Bottom-Right Corner with Dual 56×56 Concave SVG Masks:** Authentic `#f0f0f0` inverse-radius cutout (`border-top-left-radius: 3.5rem`) housing the `Documentation` / `Library ›` launcher and two `56×56` concave SVG corner masks.
- **Frosted Yielders Card & Center Navigation:** Bottom-left `backdrop-filter: blur(24px)` card (`5.2K Active Yielders` + `Join Discord` pill) and top bar (`Ecosystem`, `Economics ›`, `Developers`, `Governance ›`, and `Book Demo ↗`).
- **Interactive Smart Vault Strategy Simulator & Institutional Modal (+15–20% Creative Enhancements):** Live strategy switcher (`stRIVR Liquid Vault`, `NFT Floor Stream`, `Delta-Neutral Treasury`) that dynamically updates Net APY, Vault TVL, Unstake Latency, and Active Yielders, plus an accessible modal (`#rivrModal`).
