# Semaan 1.0.0

A static independent-designer portfolio with an orange/white hero, mirrored-sunglasses portrait, selected work, about, expandable services and email contact.

## Start
Read CUSTOMISE.md for exact edits, ten steps and twelve complete AI prompts. Extract all nine files and open index.html beside assets/. No framework, package installation, build, CDN, remote font or API needed.

## Behavior
Mobile menu supports Escape, keyboard and link-close. Desktop gallery shortcut and anchors navigate actual sections. Native work/service details work without JavaScript. Scroll entrances are finite 620ms and default ON under OS reduced motion. No perpetual loop, tracking, backend, form submission, account system, booking or PDF résumé. Email opens a mail app and never claims delivery.
