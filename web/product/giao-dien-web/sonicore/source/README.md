# Sonicore 1.0.0

Read CUSTOMISE.md first: ten steps, twelve complete AI prompts and a counted edit map. Extract the complete folder and double-click index.html. Keep assets/ alongside it. Ten files: HTML, CSS, JS, four local WebP product renders and three documents. No framework, installation, build, API, font download or CDN.

## Working interactions
Three-preset spatial soundstage and equalizer controller (`CINEMA`, `STUDIO`, `GAMING`), six-part exploded hardware callout selector (`PROTEIN LEATHER`, `DYNAMIC DRIVER`, `HI-RES AUDIO CHIP`, `ACOUSTIC CHAMBER`, `NEODYMIUM MAGNET`, `SPATIAL PROCESSING`) and four-dot review highlight controller with keyboard arrows and horizontal swipe. Finite directional transitions cancel earlier input. Mobile menu closes on a link, Escape and desktop resize. Native specification disclosure works without JS. Scroll-triggered finite reveals and a session-only Pause motion button. Reload enables motion, including under OS reduced-motion settings. No saved motion state. No idle animation loop.

EXPERIENCE SOUND cycles the spatial soundstage preset. PRE-ORDER NOW leads to an explicitly labelled email enquiry section; PRE-ORDER BY EMAIL opens the visitor's email application. No order is placed and no email is automatically sent. The static page includes no account, inventory, payment, checkout, tracking or backend. Without JavaScript the content, navigation, email and specifications remain accessible; interactive controls hide gracefully.
