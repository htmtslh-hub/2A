# Targo — Scaling The Platform For Your Business

A self-contained single-file, two-section landing page (`index.html`) for **Targo**, featuring **Quantico** (`400` + `700`) typography, chamfered `#15BCDF` cyan CTAs, dual autoplay-resilient CloudFront background/showcase videos (with a desktop left scrim on Section 1 and a `#15BCDF` `mix-blend-mode: hue` tint overlay on Section 2), a `<= 700px` mobile navigation drawer, and an interactive **Live QA Pipeline & Audit Modal** (15% creative enhancement).

## Quick Start
Open `index.html` directly in any modern browser or serve the folder over HTTP:
```bash
npx serve .
```
No build step or external dependencies required. See `CUSTOMISE.md` for customisation instructions and 12 AI prompts.
