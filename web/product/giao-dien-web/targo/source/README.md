# Targo — Scaling The Platform For Your Business

A self-contained single-file, two-section landing page (`index.html`) for **Targo**, featuring **Quantico** (`400` + `700`) typography, chamfered `#15BCDF` cyan CTAs with a trailing `22×1px` rule, dual autoplay-resilient CloudFront background/showcase videos (with universal H.264 `yuv420p` fallbacks in `assets/`, a desktop left scrim on Section 1, and a `#15BCDF` `mix-blend-mode: hue` tint overlay flush to the right screen edge on Section 2), and a `<= 700px` mobile navigation drawer.

## Quick Start
Open `index.html` directly in any modern browser or serve the folder over HTTP:
```bash
npx serve .
```
No build step or external dependencies required. See `CUSTOMISE.md` for customisation instructions and 12 AI prompts.
