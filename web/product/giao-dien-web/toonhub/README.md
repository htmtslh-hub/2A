# TOONHUB (`toonhub`) — 3D Character Figurine Carousel Hero

- **Mã sản phẩm (Catalog ID):** `t68`
- **Slug:** `toonhub`
- **Phiên bản:** `1.0.0`
- **Danh mục:** Sản phẩm / Thương mại (`Interactive 3D Collectible Showcase`)
- **Công nghệ:** React 18 + TypeScript + Vite + Tailwind CSS + `lucide-react` (kèm bản dựng tĩnh `source/built/`)

## Cấu trúc sản phẩm trong kho lưu trữ

- `source/`: Mã nguồn hoàn chỉnh + tài liệu bàn giao (`CUSTOMISE.md`, `README.md`, `LICENCE.txt`, `THIRD-PARTY-LICENSES.txt`) + bản dựng tĩnh `built/`.
- `toonhub.zip`: Gói bàn giao khách hàng được đóng gói và kiểm định tự động qua `tools/dong-goi.mjs toonhub --ngoai-le`.
- `reviews/1.0.0/`: Hồ sơ nghiệm thu gồm `BRIEF.md`, `QA.md`, `check.cjs`, `checks.json` và ảnh chụp màn hình trên 4 trình duyệt (Chromium, Firefox, Edge, Cốc Cốc).
