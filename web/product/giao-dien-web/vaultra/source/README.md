# Vaultra — Crypto Finance Ecosystem Hero

A single-file, one-screen **landing hero** (`index.html`) for the fictional crypto finance platform **Vaultra** (*"Innovative Crypto Financial Solutions / For Any Investment Challenge"*), built with plain HTML, CSS, and vanilla JavaScript with zero framework or build step.

## Highlights
- **Dotted Particle Globe Still & Seamless 4s Video Loop:** Pairs the `1672×941` dotted particle globe plate (`#globeStill`, with latitude rings, red/blue/magenta rim glows, and diagonal light lines) with an identical-geometry `1280×720` muted 4-second loop (`#globeVideo`) whose last second crossfades into the first and fades in (`0.85s`) once its first frame is ready.
- **Ultra-Wide & Phone Feather Masks:** Both layers stretch to a shared `.globe-plate` feathered horizontally on ultra-wide screens (`min-aspect-ratio: 20/10`) and vertically at the top on phones (`<= 820px`).
- **Inter Display 300 & Poppins 400/500 Typography:** Two-line `66px` headline in `Inter Display 300` with a soft pink-to-lilac gradient at both ends (`#f49cd4` → `#deb6ff` → `#ffffff` → `#deb6ff` → `#f49cd4`), paired with `Poppins` for the navigation bar, glass badge (`⚡ Revolutionizing Crypto Finance`), body copy, and white `Get Started →` CTA pill.
- **Glass Coin Chips & Curved Scroll Hint:** Four round frosted-glass coin chips (`₿`, `Ξ`, `₮`, and a hexagonal prism token) ride the diagonal light lines at the edges, complemented by a bottom mouse-scroll hint framed by curved `USDT` and `ETH` arc labels.
- **1.6s CSS Entrance & Interactive Ecosystem Simulator (15% Creative Boost):** Choreographed `1.6s` CSS rise-in sequence (disabled alongside video under `prefers-reduced-motion: reduce`), plus an interactive `"EN ⌄"` currency popover and 3-tab Vaultra Ecosystem & Vault Simulator modal.

## Quick Start
Open `index.html` directly in any modern browser or serve the folder over HTTP:
```bash
npx serve .
```
