# Verdant 1.0.0

A static café showcase with matcha, mango and strawberry drinks, cream/green styling, original generated imagery, a directional carousel and a scroll-driven craft scene.

Start with CUSTOMISE.md: ten steps, twelve complete AI prompts and exact edits. Extract all eight files and double-click index.html. No installation, build, remote fonts, account or API is needed. Keep assets/ beside index.html.

## Included
index.html; assets/css/style.css; assets/js/main.js; assets/img/drinks.webp; assets/img/bean.webp; CUSTOMISE.md; README.md; LICENCE.txt.

## Working interactions
Three flavours via thumbnails, arrows, keyboard and swipe; medium/small/large preference buttons; accessible product detail dialogs; mobile menu; internal links; a mailto contact link; reveal and a sticky scroll product scene. Pause motion applies to this page only; opening/reloading defaults ON even with an OS reduced-motion preference. Carousel motion uses finite requestAnimationFrame callbacks rather than depending on CSS/WAAPI.

No shopping cart, backend, order submission, live search, payment or email service is bundled. Prices, menu and brand are illustrative. hello@verdant.example is a reserved demo address and must be replaced. Size selection does not change pricing. Details include an illustrative dairy disclosure, not verified allergen advice. No-JS retains the complete menu and anchors and hides JS-only controls.

## Editing
Change tokens in CSS :root. Product data is in the products array in main.js and also static HTML. The three drinks use a single transparent image with CSS showing equal thirds. Update all instances together. See the edit map before replacing images.

## Verification
Browser evidence and outstanding limitations are recorded in the product QA report. Do not interpret system font availability as identical typography on every OS. Safari and physical mobile devices are not verified unless stated in that report.
