# Vertex Shops 1.0.0

Read CUSTOMISE.md for editing and LICENCE.txt for terms.

Static SaaS hero: fitted type, fixed desktop canvas, 37-card 3D carousel, foreground Glow store mock and separate tablet/phone layouts. Extract the ZIP and open index.html. CSS/JS are inline; three documents are not runtime dependencies. No build, framework or installation. Fifteen supplied CloudFront images and Google Fonts Poppins/Playfair Display require internet. Missing images show gradients; offline typography differs.

The nav/CTA href="#" links are demo anchors. WhatsApp needs your real recipient. The storefront is a visual mock, without checkout, search, pricing, shop onboarding, accounts or payment. Connect verified destinations before business use.

Edit inline HTML/CSS, SHOTS, creative(), layout() and resize(); preserve phone cleanup, badge spacing, button clipping and browser/ring overlap.

Windows Chromium 153, Edge 155 and CocCoc 152 were checked at widths 320–2560, including menu/Escape/focus, rotation, image failure and reduced motion. No Safari/real-device certification. Remote image redistribution rights are not granted by the source licence.
