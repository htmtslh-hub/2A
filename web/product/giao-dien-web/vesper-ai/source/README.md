# Vesper.ai 1.0.0

Read `CUSTOMISE.md` first: ten steps, twelve complete AI prompts and a counted edit map. Extract the complete folder and double-click `index.html`. Keep the local font files (`inter.woff2`, `instrument-serif-italic.woff2`) and hero video (`hf_20260818_072341_50851634-bbc3-4c33-9acc-7647d4db44aa.mp4`) alongside `index.html`. No framework, installation, build step or backend required.

## Working interactions
Single-viewport operational AI infrastructure hero with liquid-metal navigation pills (`Benefits`, `How It Works`, `FAQs`, `Pricing`), liquid-glass action buttons (`Start for Free`, `Get Early Access`, `Watch Demo`), a 9-keyframe spring-settle entrance choreography (`.appear--scale`, `.appear--soft`, `.appear--pop`, `.appear--rise`, `.line-inner`), a responsive mobile burger drawer (`<=900px`) with backdrop, `Escape` key and `matchMedia` auto-close, and a session-only `Pause motion` toggle in the footer stats bar. Motion defaults ON across all browsers including under OS reduced-motion settings, and includes a finite `requestAnimationFrame` fallback when CSS animations are unavailable.
