# Wander Far — Editorial Travel-Booking Landing Hero

A self-contained, single-file, one-screen travel-booking landing hero (*"Wander far. Rest easy."*), built with plain HTML5, CSS3, and vanilla JavaScript with zero frameworks and no build step.

## Files Included

- `index.html` — Complete self-contained markup, styles, and scripts (1446×1088 scaling system `--u = min(100vw/1446, max(100dvh/1088, .78px))`, `Inter Display 700` 90u two-line headline + `Inter 400/500/600` + `IBM Plex Mono`, `Stays · Flights · Experiences` tabs with `#0A2A72` active underline, hairline-bordered 4-cell search bar with `#00286E` fjord navy button, square-cornered Norwegian fjord photo panel with 5s looping video fade-in and `"Geirangerfjord, Norge · 62.10° N"` chip, one-shot CSS entrance, and `<= 820px` stacked mobile layout with `object-position: 74%`).
- `CUSTOMISE.md` — 10-step customisation guide and 12 AI prompts.
- `LICENCE.txt` — Commercial and client use licence.
- `README.md` — Quick-start instructions.

## Quick Start

1. Extract all 4 files from `wander-far.zip`.
2. Open `index.html` directly in any modern browser, or serve the folder over a local static server (`npx serve .` or `python -m http.server 8080`).
3. Follow `CUSTOMISE.md` to replace the headline, search defaults, fjord still/video URLs, or location chip coordinates.
