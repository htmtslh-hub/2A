# Japan Trails

Start with CUSTOMISE.md. Open index.html after extracting the complete folder. Static HTML/CSS/JS with two locally generated WebP photographs; no build or external scripts. Google Fonts is optional with system fallbacks.

Version 1.1.0. The owner explicitly requested replacement of the first storefront product with this Japan travel concept. Generated photos, one transparent character cutout, eight source files and a larger ZIP are accepted scope exceptions to the old SVG-only six-file/20,480-byte profile. Menu is the only JavaScript enhancement; anchor and email links work without JS. No bookings, newsletter, search, social accounts or payment service are simulated. hello@example.com is a demo address.

Built-in ImageGen assets: fuji.webp (Fuji, pagoda, sunrise and blossoms); kyoto.webp (traditional lantern-lit street). These are generated imagery, not documentary proof. Terms in LICENCE.txt retain Forge Zone commercial conditions. Font Barlow Condensed is loaded from Google Fonts under the SIL Open Font License 1.1; its verified source is listed in LICENCE.txt section 5.
